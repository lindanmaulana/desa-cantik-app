# 📂 Desa Cantik App - Architecture & Folder Structure

Dokumen ini mencatat rencana pengorganisasian modul dan struktur file aplikasi.

*(Catatan: Bagian ini dapat dikembangkan lebih lanjut sesuai dengan implementasi struktur folder Laravel 11).*

## 🏗️ Desain UI & Konsep Modul
*   Aplikasi menggunakan pendekatan **Modular Profile Page** pada sisi antarmuka pengguna.
*   Halaman profil warga bersifat dinamis dengan menyediakan tombol aksi mandiri (`➕ Tambah Profil`) untuk pengisian data sekunder (Pendidikan, Pekerjaan, Kesehatan, Rumah, dan UMKM).
